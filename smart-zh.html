How Smart Works

Smart 来自你的 Mac，
不是云端用户画像。

Smart Launcher 的核心推荐建立在本机 App 活动与使用模式之上。它不依赖 Screen Time，也不要求云端 AI 才能完成核心推荐。

1. 本地活动信号

通过 macOS 提供的应用生命周期与前台切换事件，在本机记录必要的 App Activity / Usage Session 信号，包括启动、前台活动、休眠与会话状态变化等。

2. 使用模式

Smart Engine 使用 recency、frequency、duration、time-of-day，以及 App sequence / cluster 等本地统计信号形成推荐依据。

3. 渐进式推荐

新安装时不假装“已经懂你”。随着本地证据增加，推荐从冷启动逐步形成更稳定的个性化结果。

4. 可选上下文

Calendar 等上下文只有在用户明确开启并授予相应权限后才参与判断；关闭后核心启动和基础 Smart 仍然可用。

5. 可查看

Usage Insights 用于展示 Smart 所观察到的本地使用信号，使推荐逻辑更容易理解和检查。

6. Local-first

核心 Smart Engine 不依赖后端或云端 AI。未来即使加入系统级本地智能能力，也应作为可选增强，而不是核心依赖。

Privacy boundary

权限和数据边界必须清楚。

Smart Launcher 的目标不是建立跨设备广告画像，也不是把 App 使用历史作为云端服务的原料。核心学习数据保留在设备侧；额外上下文由用户控制并遵循 macOS 权限模型。
