Product Features

熟悉的启动方式，
更聪明的下一步。

Smart Launcher 是面向 macOS 的原生启动器。Classic 保留熟悉的 App 网格与文件夹体验，Smart 则根据本机使用模式逐步提供更有用的推荐。

Classic Launcher

保留 App 网格、文件夹、分页和直接启动 App 的核心体验。Smart 是增强层，不会取代基础启动能力。

Smart Page

通过 Continue、Recent、New & Changed 等区域，把更可能需要的 App 提前呈现出来。

Local Learning

在 Mac 本机形成使用模式。核心 Smart Engine 不要求云端 AI 服务，也不需要上传完整 App 使用历史。

Usage Insights

让用户查看 Smart 所使用的本地时长和使用模式信号，避免推荐机制成为不可解释的黑盒。

Calendar Context

在用户明确授权后，日历上下文可以成为 Smart 的附加信号。基础能力与高级能力根据 Free / Pro 版本提供。

Smart Rules

将重复的上下文和使用习惯整理为可复用规则。Free 提供基础能力，Pro 扩展规则数量与用户批准的自动化能力。

Menu Bar

通过原生 macOS 菜单栏入口快速访问 Smart Launcher 和相关设置。

Universal Mac

面向 Apple Silicon 与 Intel Mac 的 Universal 应用，最低支持 macOS 15。

中文 + English

Smart Launcher 界面支持简体中文和英文，App 名称遵循应用自身提供的本地化显示名称。

Product status

公开说明只区分已提供与规划中的能力。

当前可用能力按实际 Release 状态发布；尚未进入正式版本的 Pro 扩展能力会明确标注为 Planned / Coming soon，不会作为已交付功能宣传。
