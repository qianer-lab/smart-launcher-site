# Smart Launcher Site

Official public website and release home for **Smart Launcher for macOS**.

## Website

This repository hosts the public Smart Launcher product website, including:

- English and Simplified Chinese landing pages
- Privacy Policy, Terms of Use, and Refund Policy
- Product screenshots and promotional assets
- GitHub Pages deployment

## Releases

Signed and notarized Smart Launcher DMG builds will be published through **GitHub Releases**, not committed to the Git repository.

Release assets are expected to include:

- `Smart-Launcher-<version>-universal.dmg`
- SHA-256 checksum
- Release notes

## Compatibility

- macOS 15 and later
- Apple Silicon and Intel Macs

## Source code

This repository is for the public website and binary releases. Smart Launcher application source code is maintained separately and is not published here.
